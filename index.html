Notification limitations (please read)

  • Notifications only work while this page is open in a Chrome tab. If you close the tab or Chrome, no reminders will appear.
  • The page checks for due doses about every 30 seconds. Chrome may slow this down for background tabs, so a notification can arrive up to about a minute late.
  • You must click "Enable notifications" and choose Allow. If you chose Block, you have to re-allow it in Chrome's site settings.
  • Chrome may not allow notifications for pages opened directly from a file (the address starts with file://). If the test notification does not appear, open the folder in VS Code and use the "Live Server" extension, which opens the page at http://localhost.
  • Your operating system's "Do Not Disturb" / Focus mode can hide notifications.
  • This prototype does not send notifications to phones, does not work when the device is off, and does not send SMS or email.
  • Even without notification permission, a "Due now" box appears at the top of the page while it is open.
  • A notification is only sent for a dose that became due within the last 60 minutes and is still unmarked.

Dose Tracking

Date:

"Pending" means a dose has not been marked yet. Each scheduled dose can have only one status; changing it replaces the old status (no duplicates). You cannot mark doses on future dates, and "Missed" can only be set once the scheduled time has passed.

Overdue = more than 60 minutes past the scheduled time and still unmarked (this includes earlier days).
